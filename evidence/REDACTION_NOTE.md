The first trial used CODEX_FORCE_AUTH_JSON=1 (as in the recruitment example). Harbor treated this non-secret flag value as a redaction string and replaced digit 1 throughout exported logs, corrupting numeric JSON literals. Original exports are preserved. decoded-trial-1 contains derived readable copies restoring this known flag value only. Trial reward is 0.0 and exception_info null even in the original export. Subsequent trials use equivalent truthy yes to avoid numeric corruption. No task, answer, reward or test was changed.

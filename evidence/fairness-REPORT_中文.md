# 失败分析与补充验证

## 结果摘要

- GPT-6 Sol 与 DeepSeek 各三次独立测试均正常结束，未通过验证器。
- 保存的六份程序在三个隐藏数据集上完成18组离线重放，补齐验证检查后，六份程序仍未整体通过。
- 参考解通过全部8项检查；9项正负控制均符合预期。

本次补充验证未调用模型，属于已保存程序的重放与重新评分。完整测试配置和后续变更见[评测报告](../reports/RESULTS.md)。

## 失败原因核对

| 提交 | 重现的主要失败 |
| --- | --- |
| GPT 1 | 两个数据集的静态投影误差为165.225、146.516px；无滑移数据集通过 |
| GPT 2 | 三个数据集的投影误差为119.254、116.421、134.980px |
| GPT 3 | 一个数据集滑移段数错误，另一个投影误差为118.030px；无滑移数据集通过 |
| DeepSeek 1 | 三个数据集均出现负相机深度 |
| DeepSeek 2 | 三个数据集的投影误差为238.871、383.069、401.222px |
| DeepSeek 3 | 两个数据集安装平移超出0.25m上限，另一个投影误差为188.613px；原测试还存在冲突重复包处理错误 |

模型可见说明已明确变换方向、编码器偏差的加法约定、时钟与滚动快门公式、记录内命名空间、滑移帧索引及数值边界。九条隐藏记录均满足声明的3px名义投影分离条件，实测最小值为4.28157px。

另对输出尝试了六种常见约定修正：编码器偏差取反或左右交换、相机变换求逆或旋转转置、安装变换求逆或旋转转置。没有使失败案例通过。现有证据不支持所有失败都由同一个符号约定造成；这组有限检查不排除其他算法或实现问题。

## 验证器补强

发现未滑移臂的小幅位置变化可能落在投影容差内，因此新增直接检查：未受影响臂在相邻段的安装矩阵逐元素差必须小于 `1e-5`。受影响臂仍按几何投影评分，不要求参数等于参考答案。

| 检查 | 结果 |
| --- | --- |
| 真值答案 | 接受 |
| `1e-7` 级舍入误差 | 接受 |
| 未滑移臂平移1mm | 拒绝 |
| 未滑移臂旋转1mrad | 拒绝 |
| 完整参考解 | 8/8通过 |
| 六份保存提交重新评分 | 均未整体通过 |

这项修复补齐了偏宽松的检查，不是原测试失败的原因。代码差异见[验证器补丁](verifier-fix.patch)。
